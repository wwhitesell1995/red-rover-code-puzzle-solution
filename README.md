# Operating Instructions
There are two ways that this applications can be tested.

1. Use dotnet run in the Red-Rover-Code-Puzzle-Solution folder and access the swagger page generated by going to [localhost:5000](http://localhost:5000). The tree controller/get section should allow for the following parameters to be passed
    * input - This field allows for a string input to be passed into the controller and be generated into a tree. The expected format is for the tree to specify levels based on parenthesis ( indicates the start of a child for a parent and ) indicates the ending of a parent's children.
    * isOrdered - Specifies if the tree and it's children's nodes are ordered alphabetically (true) or by index order (false). For the requested input this means that isOrdered false (default) will give the first output whereas isOrdered true will give the second output.
2. Use dotnet test to validate that the test conditions pass. The tests should pass for the provided input/output (as well as other test conditions that need to pass for validity).
